## The kernel's side (question 3, §6)

Kernel threads: their process is pid 2 or has pid 2 as its parent; a thread goes to the first name group it matches (§3's order), by its name in the second snapshot. A kworker's name carries its current work item, so a kworker running an rknpu item at the second snapshot counts in the npu group. A thread of the second snapshot only counts in full; one of the first only is counted and listed, its contribution unknown (§1).
